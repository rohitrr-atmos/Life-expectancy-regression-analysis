# Statistical Modeling of Life Expectancy using Multiple Linear Regression (R)

## Overview

Developed and validated simple and multiple linear regression models in
**R** to investigate the socio-economic determinants of life expectancy
using a country-level dataset. The project focused on identifying
statistically significant predictors while building an interpretable and
parsimonious predictive model.

------------------------------------------------------------------------

## Dataset

The analysis was conducted using an **80% training subset** of a
country-level dataset containing demographic, economic, environmental,
and healthcare indicators.

**Response Variable** - Life Expectancy

**Predictor Variables** - Population - Land Area - Rural Population
(%) - Government Health Expenditure (%) - Internet Access (%) - Birth
Rate - Elderly Population (%) - CO₂ Emissions (Metric Tons per Capita) -
GDP per Capita - Cell Phone Subscriptions

------------------------------------------------------------------------

## Objectives

-   Develop a parsimonious multiple linear regression model for
    predicting life expectancy.
-   Identify statistically significant socio-economic predictors.
-   Evaluate model assumptions and statistical validity.
-   Interpret results to generate evidence-based insights.

------------------------------------------------------------------------

## Methodology

The project followed a structured statistical modeling workflow:

-   Data cleaning and preprocessing
-   Exploratory Data Analysis (EDA)
-   Simple and Multiple Linear Regression
-   Residual Diagnostics
-   Assessment of linearity assumptions
-   Predictor and response variable transformations
-   Multicollinearity assessment using Variance Inflation Factor (VIF)
-   Forward and Backward Stepwise Model Selection
-   Model validation and interpretation

------------------------------------------------------------------------

## Key Outcomes

-   Developed a statistically robust multiple linear regression model.
-   Identified significant socio-economic factors associated with life
    expectancy.
-   Validated model assumptions through residual analysis and diagnostic
    testing.
-   Generated interpretable, evidence-based insights from real-world
    data.
